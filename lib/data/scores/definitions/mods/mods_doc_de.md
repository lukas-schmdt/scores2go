# Multiple Organ Dysfunction Score (MODS)

Der MODS quantifiziert das Ausmaß der Organdysfunktion bei kritisch kranken Patienten über sechs Organsysteme. Er wurde entwickelt, um ein reproduzierbares, objektives Maß für die Schwere des Organversagens für die ITS-Outcomeforschung und klinisches Monitoring bereitzustellen.

## Bewertungssystem

Jedes Organsystem wird mit 0–4 Punkten bewertet. Der Gesamtwert reicht von **0 bis 24**.

### Respiratorisch — PaO₂ / FiO₂-Verhältnis (mmHg)

| Punkte | P/F-Verhältnis |
|--------|----------------|
| 0 | > 300 |
| 1 | 226–300 |
| 2 | 151–225 |
| 3 | 76–150 |
| 4 | ≤ 75 |

### Renal — Serum-Kreatinin

| Punkte | µmol/L | mg/dL |
|--------|--------|-------|
| 0 | ≤ 100 | ≤ 1,1 |
| 1 | 101–200 | 1,2–2,3 |
| 2 | 201–350 | 2,4–3,9 |
| 3 | 351–500 | 4,0–5,7 |
| 4 | > 500 | > 5,7 |

Bewertung ohne Berücksichtigung einer Nierenersatztherapie.

### Hepatisch — Serum-Bilirubin

| Punkte | µmol/L | mg/dL |
|--------|--------|-------|
| 0 | ≤ 20 | ≤ 1,2 |
| 1 | 21–60 | 1,3–3,5 |
| 2 | 61–120 | 3,6–7,0 |
| 3 | 121–240 | 7,1–14,0 |
| 4 | > 240 | > 14,0 |

### Kardiovaskulär — Druckkorrigierte Herzfrequenz (PAR)

```text
PAR = Herzfrequenz × ZVD / MAP
```

| Punkte | PAR |
|--------|-----|
| 0 | ≤ 10 |
| 1 | 10,1–15 |
| 2 | 15,1–20 |
| 3 | 20,1–30 |
| 4 | > 30 |

ZVD = zentraler Venendruck (rechtsatrialer Druck), MAP = mittlerer arterieller Druck, beide in mmHg.

### Hämatologisch — Thrombozytenzahl (×10³/µL)

| Punkte | Thrombozyten |
|--------|--------------|
| 0 | > 120 |
| 1 | 81–120 |
| 2 | 51–80 |
| 3 | 21–50 |
| 4 | ≤ 20 |

### Neurologisch — Glasgow Coma Scale (GCS)

| Punkte | GCS |
|--------|-----|
| 0 | 15 |
| 1 | 13–14 |
| 2 | 10–12 |
| 3 | 7–9 |
| 4 | ≤ 6 |

GCS direkt bewerten, ohne Korrektur für Sedierung.

## Interpretation des Gesamtwertes

| MODS Gesamt | Schweregrad | Vorhergesagte Mortalität |
|-------------|-------------|--------------------------|
| 0 | Keine Dysfunktion | ~0 % |
| 1–4 | Leicht | ~1–7 % |
| 5–8 | Mäßig | ~3–17 % |
| 9–12 | Schwer | ~9–35 % |
| 13–16 | Sehr schwer | ~24–69 % |
| > 16 | Maximal | ~49–100 % |

## Klinische Hinweise

- MODS ist für die **tägliche Bewertung** konzipiert — Verlaufstrends über den ITS-Aufenthalt verfolgen.
- Im Gegensatz zum SOFA enthält MODS keine Koagulationskomponente und verwendet PAR statt Vasopressordosis für die kardiovaskuläre Bewertung.
- Die kardiovaskuläre PAR-Komponente erfordert eine ZVD-Messung; ohne zentralen Venenkatheter ist diese Komponente nicht zuverlässig bestimmbar.
- Sedierung verfälscht die neurologische Komponente; entsprechend dokumentieren.
