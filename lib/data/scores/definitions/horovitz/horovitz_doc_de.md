# Horovitz-Quotient (PaO₂ / FiO₂-Verhältnis)

Der Horovitz-Quotient ist das Verhältnis des arteriellen Sauerstoffpartialdrucks (PaO₂) zur inspiratorischen Sauerstofffraktion (FiO₂). Er ist das Standardmaß für die Oxygenierungseffizienz und bildet die Grundlage der ARDS-Berlin-Definition zur Schweregradklassifikation.

## Formel

```text
Horovitz-Quotient = PaO₂ (mmHg) / FiO₂ (Fraktion)
```

**Beispiel:** PaO₂ = 80 mmHg, FiO₂ = 40 % → 80 / 0,40 = **200 mmHg**

## Interpretation

| Quotient (mmHg) | Klassifikation |
|-----------------|----------------|
| ≥ 400 | Normale Oxygenierung |
| 300–399 | Leichte Hypoxämie |
| 200–299 | Leichtes ARDS (Berlin-Definition) |
| 100–199 | Moderates ARDS (Berlin-Definition) |
| < 100 | Schweres ARDS (Berlin-Definition) |

## ARDS-Berlin-Definition (2012)

Die Berlin-Definition erfordert neben dem P/F-Verhältnis die Erfüllung aller folgenden Kriterien:

- **Zeitlicher Verlauf:** akuter Beginn innerhalb von 1 Woche nach einem bekannten klinischen Ereignis oder neuen bzw. sich verschlechternden Atemwegssymptomen
- **Bildgebung:** bilaterale Verschattungen, die nicht vollständig durch Ergüsse, Atelektasen oder Rundherde erklärt werden
- **Ödemursache:** Atemversagen nicht vollständig durch Herzinsuffizienz oder Flüssigkeitsüberlastung erklärbar
- **PEEP:** ≥ 5 cmH₂O für alle Schweregrade

:::note PEEP-Korrektur
Der Horovitz-Quotient wird **unter den aktuellen Beatmungseinstellungen** einschließlich PEEP gemessen. Ohne PEEP ≥ 5 cmH₂O kann die ARDS-Klassifikation gemäß Berlin-Definition nicht angewendet werden.
:::

## Klinische Hinweise

- Der Quotient sollte aus einer **arteriellen Blutgasanalyse** bestimmt werden (keine SpO₂-basierten Schätzwerte).
- FiO₂ muss die **tatsächlich applizierte** Konzentration widerspiegeln — Kontrolle am Beatmungsgerät oder High-Flow-System.
- Serielle Messungen verfolgen das **Ansprechen auf Interventionen** (Bauchlagerung, PEEP-Titration, Rekrutierungsmanöver).
- Das **SpO₂/FiO₂ (SF)-Verhältnis** ist ein nicht-invasives Surrogat: SF ≈ 57 + 0,61 × PF (verwendbar, wenn keine BGA verfügbar ist).
