# Finnegan Neonatal Abstinence Score (NAS)

The Finnegan NAS is the most widely used tool for assessing the severity of neonatal opioid withdrawal syndrome (NOWS) in newborns exposed to opioids in utero. It evaluates 21 signs across three domains: central nervous system (CNS), metabolic/vasomotor/respiratory (MVR), and gastrointestinal (GI).

## Scoring Domains

### Central Nervous System (max ~29 points)

| Sign | Points |
|------|--------|
| Cry: normal | 0 |
| Cry: high-pitched | 2 |
| Cry: continuous high-pitched | 3 |
| Sleep after feeding: > 3 h | 0 |
| Sleep after feeding: < 3 h | 1 |
| Sleep after feeding: < 2 h | 2 |
| Sleep after feeding: < 1 h | 3 |
| Moro reflex: normal | 0 |
| Moro reflex: hyperactive | 2 |
| Moro reflex: markedly hyperactive | 3 |
| Tremors when disturbed: none | 0 |
| Tremors when disturbed: mild | 1 |
| Tremors when disturbed: moderate–severe | 2 |
| Tremors when undisturbed: none | 0 |
| Tremors when undisturbed: mild | 3 |
| Tremors when undisturbed: moderate–severe | 4 |
| Increased muscle tone | 2 |
| Excoriation | 1 |
| Myoclonic jerks | 3 |
| Generalised convulsions | 5 |

### Metabolic / Vasomotor / Respiratory (max ~14 points)

| Sign | Points |
|------|--------|
| Sweating | 1 |
| Fever < 37.2 °C | 0 |
| Fever 37.2–38.3 °C | 1 |
| Fever > 38.3 °C | 2 |
| Yawning (> 3–4×/interval) | 1 |
| Mottling | 1 |
| Nasal stuffiness | 1 |
| Sneezing (> 3–4×/interval) | 1 |
| Nasal flaring | 2 |
| Respiratory rate 60–80 /min | 1 |
| Respiratory rate > 80 /min | 2 |
| Retractions | 2 |

### Gastrointestinal (max ~11 points)

| Sign | Points |
|------|--------|
| Excessive sucking | 1 |
| Poor feeding | 2 |
| Regurgitation | 2 |
| Projectile vomiting | 3 |
| Loose stools | 2 |
| Watery stools | 3 |

## Score Interpretation

| Score | Severity | Recommended Action |
|-------|----------|--------------------|
| < 8 | Mild | Supportive care (swaddling, decreased stimulation, breastfeeding) |
| 8–11 | Moderate | Consider pharmacotherapy if two consecutive scores ≥ 8 |
| ≥ 12 | Severe | Pharmacotherapy indicated |

## Clinical Notes

- Assessments are typically performed **every 3–4 hours** (before feeds) or more frequently if scores are elevated.
- **Two consecutive scores ≥ 8** (or three ≥ 8 in 24 h in some protocols) is the standard threshold to initiate pharmacotherapy.
- **Morphine** (oral) is the first-line pharmacological agent in most centres; **buprenorphine** is increasingly used as an alternative.
- The score should always be interpreted in the clinical context — maternal medications, gestational age, and comorbidities affect the presentation.
- The **modified Finnegan** or **Eat Sleep Console (ESC)** tool is used in some centres as a simpler alternative focused on function rather than signs.
