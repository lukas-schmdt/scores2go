# Confusion Assessment Method for the ICU (CAM-ICU)

The CAM-ICU is the most widely validated tool for delirium detection in mechanically ventilated and non-verbal ICU patients. It adapts the original CAM (Inouye 1990) into a two-step algorithm completed in under 2 minutes. Delirium is present when features **1 + 2 + (3 or 4)** are all positive.

:::info Sedation First
Assess the RASS level before applying the CAM-ICU. If RASS = **−4 or −5** (deep sedation / unarousable), the patient cannot be assessed — document as *unable to assess* and re-evaluate once sedation is lightened.
:::

## Algorithm Overview

```
Feature 1: Acute onset or fluctuating course?
    ↓ Yes
Feature 2: Inattention?
    ↓ Yes
Feature 3: Altered level of consciousness (RASS ≠ 0)?
    OR
Feature 4: Disorganised thinking?
    ↓ Yes (either or both)

→ CAM-ICU POSITIVE (Delirium present)
```

If any feature is **No**, CAM-ICU is **negative**.

## Feature Details

### Feature 1 — Acute onset or fluctuating course
- Is there an acute change from baseline mental status? **OR**
- Has the patient's mental status fluctuated over the past 24 hours?
- Sources: Serial RASS scores, GCS, nursing documentation, family input.

### Feature 2 — Inattention (SAVE letter test)
Read the letters **S-A-V-E-A-H-A-A-R-T** aloud at 1 second intervals. Ask the patient to squeeze your hand each time they hear the letter **"A"**.

| Correct responses | Score |
|---|---|
| Squeezes on each A (positions 2, 5, 7, 8) | +1 each |
| Does not squeeze on non-A letters | +1 each |
| **Total** | **/10** |

**Score < 8 = Inattention present** (Feature 2 positive).

*Alternative*: Use the CAM-ICU pictures attention test if the SAVE test is not feasible.

### Feature 3 — Altered level of consciousness
Any RASS score **other than 0** (alert and calm) counts as positive — this includes agitation (RASS +1 to +4) and any level of sedation (RASS −1 to −3).

### Feature 4 — Disorganised thinking
Ask the following **4 yes/no questions**:

1. Will a stone float on water?
2. Are there fish in the sea?
3. Does 1 kg weigh more than 2 kg?
4. Can you use a hammer to pound a nail?

Then give a **simple command**: "Hold up this many fingers" (hold up 2 fingers) — "Now do the same with the other hand" (without demonstrating).

**Score < 4/5 = Disorganised thinking present** (Feature 4 positive).

## Score Interpretation

| Result | Meaning |
|--------|---------|
| **CAM-ICU Positive** | Delirium present — initiate delirium management |
| **CAM-ICU Negative** | No delirium detected at this time |
| Unable to assess | RASS −4/−5 — reassess when sedation lightened |

:::tip ABCDEF Bundle
The CAM-ICU is the **D** component of the PADIS/ABCDEF bundle. It should be performed at **every nursing shift** and paired with pain assessment (A), sedation targeting (C), and early mobility (E).
:::

## Psychometric Properties

- Sensitivity: **93–100%** | Specificity: **98–100%** (vs. DSM criteria, Ely 2001)
- High inter-rater reliability (κ = 0.96)
- Validated in multiple languages and ICU settings
