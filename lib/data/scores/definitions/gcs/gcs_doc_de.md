# Glasgow Coma Scale (GCS)

Die GCS ist das weltweit am häufigsten eingesetzte Instrument zur Beurteilung des Bewusstseinsniveaus bei Patienten mit akuter Hirnverletzung. Sie erfasst drei unabhängige Subskalen — Augenöffnung (E), verbale Reaktion (V) und motorische Reaktion (M) — die jeweils getrennt bewertet und zu einem Gesamtwert von 3–15 addiert werden.

## Subskalen

### Augenöffnung (E) — max. 4 Punkte

| Score | Reaktion |
|-------|----------|
| E4 | Spontan |
| E3 | Auf Ansprache |
| E2 | Auf Schmerzreiz |
| E1 | Keine |

### Verbale Reaktion (V) — max. 5 Punkte

| Score | Reaktion |
|-------|----------|
| V5 | Orientiert |
| V4 | Verwirrt |
| V3 | Inadäquate Worte |
| V2 | Unverständliche Laute |
| V1 | Keine |

### Motorische Reaktion (M) — max. 6 Punkte

| Score | Reaktion |
|-------|----------|
| M6 | Befolgt Aufforderungen |
| M5 | Gezielte Schmerzabwehr |
| M4 | Ungezielte Schmerzabwehr |
| M3 | Abnorme Beugung (Dekortikation) |
| M2 | Streckreaktion (Dezerebration) |
| M1 | Keine |

## Interpretation des Gesamtwerts

| GCS Gesamt | Schweregrad |
|------------|-------------|
| 13–15 | Leicht |
| 9–12 | Mittelgradig |
| 3–8 | Schwer |

Ein GCS ≤ 8 gilt als konventioneller Grenzwert für ein **schweres Schädel-Hirn-Trauma** und wird häufig als Indikation zur Atemwegssicherung (Intubation) herangezogen.

## EVM-Notation

Ergebnisse werden im **EVM-Format** angegeben (z. B. E3 V4 M5 = GCS 12), um die einzelnen Subskalen-Beiträge zu kommunizieren, die einen unabhängigen prognostischen Wert besitzen.

## Hinweise zur Erhebung

- Stets die **beste** Reaktion in jeder Subskala dokumentieren.
- Bei intubierten oder aphasischen Patienten kann die Verbalkategorie nicht beurteilt werden — als **VT** (Ventiliert) oder **VA** (Aphasisch) dokumentieren; der Gesamtwert sollte diese Einschränkung widerspiegeln.
- Die motorische Subskala hat die höchste prädiktive Aussagekraft für das Outcome.
- Wiederholte Messungen im Verlauf (GCS-Trend) sind aussagekräftiger als eine Einzelmessung.
