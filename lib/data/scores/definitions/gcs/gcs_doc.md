# Glasgow Coma Scale (GCS)

The GCS is the most widely used tool for assessing level of consciousness in patients with acute brain injury. It evaluates three independent subscales — eye opening (E), verbal response (V), and motor response (M) — each scored separately and summed for a total of 3–15.

## Subscales

### Eye Opening (E) — max 4 points

| Score | Response |
|-------|----------|
| E4 | Spontaneously |
| E3 | To speech |
| E2 | To pain |
| E1 | None |

### Verbal Response (V) — max 5 points

| Score | Response |
|-------|----------|
| V5 | Oriented |
| V4 | Confused |
| V3 | Inappropriate words |
| V2 | Incomprehensible sounds |
| V1 | None |

### Motor Response (M) — max 6 points

| Score | Response |
|-------|----------|
| M6 | Obeys commands |
| M5 | Localizes pain |
| M4 | Withdraws from pain |
| M3 | Abnormal flexion (Decorticate) |
| M2 | Extension (Decerebrate) |
| M1 | None |

## Total Score Interpretation

| GCS Total | Severity |
|-----------|----------|
| 13–15 | Mild |
| 9–12 | Moderate |
| 3–8 | Severe |

A GCS ≤ 8 is the conventional threshold for **severe traumatic brain injury** and is commonly used as an indication for airway protection (intubation).

## EVM Notation

Results are reported in **EVM format** (e.g., E3 V4 M5 = GCS 12) to communicate the individual subscale contributions, which carry independent prognostic value.

## Assessment Notes

- Always record the **best** response in each subscale.
- For intubated or aphasic patients, the verbal component cannot be assessed — document as **VT** (Ventilated) or **VA** (Aphasic); total score should reflect this limitation.
- The motor subscale is the most predictive component for outcome.
- Repeated assessments over time (GCS trend) are more informative than a single measurement.
